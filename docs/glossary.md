# قاموس المصطلحات (بشرح بسيط وتشبيه)

> التشبيه الأساسي: نظامنا عبارة عن **محطة إذاعة FM حقيقية**، بس على الإنترنت.

| المصطلح | التشبيه بالإذاعة الحقيقية | الشرح التقني المختصر |
|---|---|---|
| **Cloud / السحابة** | مبنى مستأجر للإذاعة | كمبيوترات بمراكز بيانات شركة كبيرة (Oracle)، بنستأجرها بدل ما نشتري سيرفر |
| **VM / Instance / السيرفر** | غرفة داخل المبنى إلها مفتاح خاص | كمبيوتر افتراضي شغّال 24 ساعة على السحابة |
| **Region (Jeddah)** | المدينة اللي فيها المبنى | الموقع الجغرافي لمركز البيانات |
| **OCPU / RAM** | عدد الموظفين وحجم المكاتب | قوة المعالج والذاكرة |
| **Ubuntu (Linux)** | نظام إدارة المبنى | نظام تشغيل السيرفر (مثل ويندوز بس للسيرفرات) |
| **SSH** | مفتاح باب خلفي للمدير بس | اتصال مشفر بنتحكم فيه بالسيرفر عن بعد بأوامر نصية |
| **SSH Key** | مفتاح حديد بدل كلمة سر | ملفين: مفتاح خاص معك، وقفل عام على السيرفر |
| **IP Address** | العنوان الدقيق للمبنى بأرقام | رقم مثل 140.x.x.x بيحدد مكان السيرفر على الإنترنت |
| **Domain / DNS** | اسم المبنى المكتوب على اللافتة | اسم سهل (ghammas-radio.duckdns.org) بيترجم للـ IP |
| **Port** | رقم الباب بالمبنى | 22 = باب المدير (SSH)، 80/443 = باب الزوار (الويب) |
| **Firewall** | حارس على الباب | بيقرر مين بيفوت ومن أي باب |
| **Security List (OCI)** | حارس بوابة المجمع | جدار ناري على مستوى شبكة Oracle |
| **iptables** | حارس باب الغرفة | جدار ناري داخل نظام Ubuntu |
| **HTTPS / SSL / Let's Encrypt** | ظرف مختوم ومشمّع | تشفير الاتصال، والشهادة مجانية من Let's Encrypt |
| **Docker / Container** | غرف جاهزة مفروشة بتنحط داخل المبنى | بيشغّل البرامج معزولة وجاهزة بأمر واحد |
| **AzuraCast** | الإذاعة كاملة: مكتب المدير + الـ DJ + برج البث | منصة راديو مفتوحة المصدر بتجمع كل الأجزاء |
| **لوحة التحكم (Web Panel)** | مكتب مدير البرامج | صفحة ويب لرفع الأغاني وترتيبها وجدولتها |
| **Liquidsoap (AutoDJ)** | الـ DJ اللي ما بينام | برنامج بيختار الأغنية الجاية وبيدمجهم ببث متواصل |
| **Playlist** | قائمة برامج الإذاعة | مجموعة أغاني بترتيب معين |
| **Schedule / الجدولة** | جدول البرامج اليومي | أي Playlist بتشتغل بأي ساعة |
| **Icecast** | برج البث | سيرفر بياخذ صوت واحد وبيوزعه على كل المستمعين |
| **Mount Point** | رقم التردد (مثل 99.6 FM) | المسار الخاص بالبث مثل /radio.mp3 |
| **Bitrate (128kbps)** | قوة ونقاء الإشارة | كمية البيانات بالثانية، أعلى = صوت أنقى + نت أكثر |
| **Codec (MP3)** | لغة الإشارة | طريقة ضغط الصوت. MP3 بيشتغل على كل الأجهزة |
| **Listener / Client** | جهاز الراديو بالسيارة | المتصفح أو VLC بالفرع |
| **Buffer** | الراديو بيسجل كم ثانية قدام عشان ما يقطّع | تخزين مؤقت بيمنع التقطيع، بس بيعمل تأخير |
| **Latency / التأخير** | الفرق بين ما الـ DJ يحكي وأنت تسمع | سبب الفرق البسيط بالتزامن بين الفروع |
| **Rate Limiting** | الحارس بيمنعك إذا دقيت الباب كثير | حد لعدد الطلبات بوقت قصير (حماية) |
| **MFA** | مفتاح + بصمة | دخول بخطوتين: كلمة سر + كود من الموبايل |
| **Always Free** | إيجار مجاني للأبد بشروط | موارد Oracle المجانية ضمن حدود معينة |
| **Least Privilege** | ما تعطي حدا مفتاح أكثر من حاجته | افتح بس الأبواب والصلاحيات الضرورية |
